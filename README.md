# 🍽️ Karmic Canteen – Smart Meal Management System

Karmic Canteen is a smart meal management and demand forecasting platform designed to optimize canteen operations, reduce food waste, and support surplus food distribution.

The system consists of a React web dashboard for administrators and students, a Flutter-based mobile application, and a local Python machine learning server that forecasts meal demand using historical consumption patterns.

---

## 📋 Problem Statement

Institutional canteens face significant challenges balancing meal preparation with actual daily demand. A lack of visibility into student meal selections and attendance leads to:

* **Substantial Food Waste:** Over-preparing meals due to unpredictable daily participation.
* **Operational Inefficiencies:** Canteen staff struggling to manage menus, deadlines, and portion sizes manually.
* **Missed Social Impact:** No streamlined channel to notify NGOs when surplus food is available, causing edible food to go to waste instead of being distributed.

Karmic Canteen solves these issues by giving students easy pre-selection tools, giving administrators real-time tracking dashboards, utilizing machine learning to forecast next-day meal counts, and offering a direct notification system to dispatch surplus food alerts to NGOs.

---

## ✨ Current Features

### 🎓 Student Portal (React Web & Flutter Mobile)
* **Weekly Meal Selection:** Students can choose their breakfast, lunch, and snacks on a calendar view for the upcoming week.
* **Real-time Deadlines:** A visual countdown timer that prevents selections or changes after the daily cutoff time set by the admin.
* **Office-mode by Default:** Students are treated as in-office by default; no mode switching is required.

### 👨‍💼 Admin Dashboard (React Web & Flutter Mobile)
* **Live Analytics:** Track total registered students, today's active participants, total meals ordered, and a percentage breakdown of orders.
* **Menu Management:** Create, update, and publish menus for breakfast, lunch, and snacks.
* **Default Menu Manager:** Configure fallback/staple menus used when no specific menu is published for a day.
* **Staples Manager:** Manage a library of recurring staple food items.
* **Interactive AI Predictions (Web Only):** Request next-day predictions, N-day weekly forecasts, and trend insights generated by the local Python ML server.
* **Reports Generator:** Generate and export detailed meal selection and attendance reports to CSV and PDF formats (using jsPDF).
* **Festival Announcements:** Broadcast special event announcements to all students.
* **Global Settings:** Configure order deadline times, grace periods, and other operational parameters.
* **Surplus Food Notification (Flutter Mobile Only):** Input leftover/surplus meal counts to send automated email alerts directly to registered NGOs.

### 🤖 Machine Learning Demand Forecasting (Python Flask API)
* **Historical Data Syncing:** Automatically fetches Firestore meal selections and updates a local cached dataset (`canteen_history.csv`).
* **LightGBM Demand Models:** Trains individual forecasting models per menu item to project tomorrow's popular choices.
* **Forecast Ranges:** Generates predicted meal counts, opt-in rates, lower/upper confidence bounds.
* **Trend Insights Engine:** Analyzes day-of-week averages, holiday consumption deviations, and top-performing menu items.

## 🚀 Getting Started

### Prerequisites
* **Node.js** v18+ and **npm**
* **Flutter SDK** v3.0.0+ and Dart
* **Python** v3.8+ and **pip**
* A configured **Firebase Project** (Firestore, Authentication, and Cloud Functions enabled)

---

### 1. React Web Frontend Setup
1. Navigate to the web frontend directory:
   ```bash
   cd madhwa-hackathon/frontend
   ```
2. Install Node packages:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
4. Access the web interface at `http://localhost:5173`.

---

### 2. Python ML Backend Setup
1. Navigate to the machine learning directory:
   ```bash
   cd madhwa-hackathon/canteen_management_system/canteen_management_system
   ```
2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Configure Firebase credentials — place your Service Account JSON file in the folder and update `config.py` with its path.
4. Start the Flask API server:
   ```bash
   python app_with_cors.py
   ```
   *(On Windows, you can also double-click `START_ML_SERVER.bat`)*
5. The ML API server will run locally at `http://localhost:5000`.

---

### 3. Flutter Mobile Frontend Setup
1. Navigate to the mobile application folder:
   ```bash
   cd flutter-frontend/karmic_canteen_app
   ```
2. Fetch Dart dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application on a connected emulator or device:
   ```bash
   flutter run
   ```

## 👥 User Roles

| Role | Access Level | Capabilities |
| :--- | :--- | :--- |
| **Student** | Web & Mobile | Select weekly meals, view published menu, view announcements, track deadlines. |
| **Admin** | Web & Mobile | Full CRUD on menus, global settings (deadlines), live analytics, ML predictions (Web), surplus food NGO email dispatch (Mobile), reports export. |

## 📈 Current Development Status

* **React Web Frontend:** **Fully Functional.** Role-based access control (Admin/Student), weekly meal calendar selections, deadline enforcement, and offline PWA support are fully implemented. Includes a dashboard panel communicating with the local ML server.
* **Flutter Mobile Frontend:** **Fully Functional.** Mobile dashboards for students and admins, localization (English/Hindi/Kannada), local charts, and the NGO surplus mailer screen are operational.
* **Python ML Server:** **Functional Local Prototype.** Successfully loads data from Firestore, trains LightGBM models per item, predicts demand, and outputs trend insights. Communicates with the Web Frontend locally — not yet cloud-hosted.
* **Firebase Infrastructure:** Firestore collections and basic security rules are configured. Cloud Functions are currently **stubs/skeletons** with cron triggers but no active business logic.
* **RFID Integration:** **Not Implemented.** No ESP32 firmware, board code, or serial communication triggers are present in this repository.

## 🚀 Future Roadmap

* **Automated RFID Meal Collection:** Integrate RFID readers (ESP32 + MFRC522) to automatically mark meals as collected in Firestore, preventing duplicates and manual tracking errors.
* **NGO Portal:** A dedicated login dashboard for NGO users to manage profiles, view live surplus notifications, reserve meals, schedule pickups, and download impact reports.
* **Cloud-Hosted AI Pipeline:** Migrate the local Python Flask backend to a cloud environment (e.g., Google Cloud Run / Firebase Functions) so predictions run automatically and update Firestore daily.
* **Automated Food Waste Prediction:** ML algorithms that specifically predict expected leftovers by correlating selection stats with historical attendance patterns and holiday schedules.
* **Automated Reminders:** Active email/SMS/push notifications (via Firebase Cloud Messaging) to remind students to make selections before deadlines.
